# Customer Churn Prediction using Machine Learning

## Project Overview

This project predicts whether a customer is likely to leave a telecom company using Machine Learning techniques. The model was developed using the IBM Telco Customer Churn Dataset and includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation.

The objective of this project is to identify customers at risk of churn and help businesses improve customer retention strategies through data-driven insights.

---

## Dataset

Dataset: IBM Telco Customer Churn Dataset

The dataset contains customer demographic information, account details, service subscriptions, billing information, and churn status.

Target Variable:
- Churn (Yes/No)

## Machine Learning Workflow

### 1. Data Preprocessing
- Removed unnecessary columns
- Handled missing values
- Converted categorical variables into numerical values
- Performed feature scaling

### 2. Exploratory Data Analysis (EDA)
- Churn distribution analysis
- Customer behavior analysis
- Contract type analysis
- Correlation analysis

### 3. Model Building
Implemented and evaluated:

- Logistic Regression
- Random Forest Classifier

### 4. Model Evaluation
Performance metrics used:

- Accuracy Score
- Confusion Matrix
- Classification Report
- Feature Importance Analysis

---

## Results

- Achieved over 80% prediction accuracy.
- Successfully identified important factors affecting customer churn.
- Compared multiple machine learning classification models.
- Generated insights that can help improve customer retention strategies.
